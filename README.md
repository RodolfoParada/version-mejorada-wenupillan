
He Realizado un análisis UX y desarrollé una propuesta de mejora para la interfaz de la págian web https://www.wenupillan.cl, implementando optimizaciones funcionales y visuales.
Para el desarrollo utilicé tecnologías como Javascript, HTML, CSS y Bootstrap, creando componentes reutilizables mediante Web Components nativos de Javascript, con el objetivo de mejorar la experiencia de usuario y la mantenibilidad del código.


- El sitio web presenta problemas de navegación poco intuitiva, ausencia de carrito de compras, contenido mal estructurado, formularios confusos y dificultad para acceder a información clave, lo que genera confusión, alta tasa de rebote y reducción de ventas.

- La propuesta de solución consiste en optimizar la arquitectura del sitio, mejorar la navegación, implementar funcionalidades como carrito de compra, reestructurar contenido y establecer un flujo de interacción fluido.

- El proyecto permitió aplicar principios de UX, optimizar la experiencia del usuario y desarrollar componentes funcionales en JavaScript.
